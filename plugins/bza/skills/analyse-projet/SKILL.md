# Skill : analyse de projet

À utiliser lors de l’onboarding sur un dépôt existant ou avant des changements non triviaux.

## Étapes

1. Identifier le type de projet et les technologies principales.
2. Repérer les fichiers de dépendances, scripts de build et documentation.
3. Identifier les points d’entrée, fichiers de configuration et hypothèses de déploiement.
4. Détecter les outils de test, lint et qualité.
5. Résumer l’architecture, les risques et les zones d’incertitude.

## Livrable attendu

- Type de projet
- Stack principale
- Répertoires importants
- Commandes disponibles
- Risques et inconnues
- Prochaines actions recommandées
